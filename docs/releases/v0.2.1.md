# The Wanderer's Core v0.2.1

Patch for tables on the 2014 rules. dnd5e 4.x records a rules edition on every item and assumes 2024 for items
that say nothing; the runes and the Core of the Wanderer were written against the 2014 rules and now say so.
dnd5e 3.x ignores the field. Nothing else changed since v0.2.0.

**Requirements:** Foundry VTT 11 or 12, dnd5e 3.0 or later (verified against 4.4.4).

**Install or update:** in Foundry open *Add-on Modules → Install Module* and paste

```
https://github.com/Sam-W-Jones/Wanderer/releases/latest/download/module.json
```

Worlds already running v0.2.0 update from the Add-on Modules tab. Runes carved before this update keep whatever
edition tag they were created with; prying one out and carving it again refreshes it.

The feature list, the audit summary and the first-run checklist are in the
[v0.2.0 notes](https://github.com/Sam-W-Jones/Wanderer/releases/tag/v0.2.0), and the full history is in
[CHANGELOG.md](https://github.com/Sam-W-Jones/Wanderer/blob/main/CHANGELOG.md).
