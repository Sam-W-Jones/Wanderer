# The Wanderer's Core v0.1.1

Packaging release. The module itself is unchanged since v0.1.0; this release re-cuts the same content through the
tag-push workflow, which creates the GitHub release and attaches `module.json` and `module.zip` on its own.

**Requirements:** Foundry VTT 11 (verified on 11.315) and the dnd5e system (built against 3.0.x; the 3.2+
attunement model is handled too).

**Install:** in Foundry open *Add-on Modules → Install Module* and paste

```
https://github.com/Sam-W-Jones/Wanderer/releases/latest/download/module.json
```

Worlds that already have v0.1.0 installed can update from the Add-on Modules tab; nothing in the world data
changes.

The feature list, first-run checklist and known limitations are in the
[v0.1.0 notes](https://github.com/Sam-W-Jones/Wanderer/releases/tag/v0.1.0), and the full history is in
[CHANGELOG.md](https://github.com/Sam-W-Jones/Wanderer/blob/main/CHANGELOG.md).
