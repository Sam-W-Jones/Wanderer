# The Wanderer's Core v0.1.0

First release. A Foundry VTT v11 module for the dnd5e system, built around one character: a stone body with a
glowing core, whose torso carries a passive core and three craftable rune nodes.

**Requirements:** Foundry VTT 11 (verified on 11.315) and the dnd5e system (built against 3.0.x; the 3.2+
attunement model is handled too).

**Install:** in Foundry open *Add-on Modules → Install Module* and paste

```
https://github.com/Sam-W-Jones/Wanderer/releases/latest/download/module.json
```

Enable *The Wanderer's Core* in the world, then, as GM, press the **Core** button in the character's sheet header
to designate the Wanderer. The player gets the same button and a **Core** tool under the token controls.

## Highlights

- **The overlay.** The concept-art torso with four slots: a central core only the GM fills, and three nodes the
  player crafts into. Hover a slot to inspect it, click to pin it, with Open and Remove on each. A filled core
  shows a golden arcane sphere and filled nodes show runed blue spheres; the slotted item takes that sphere as its
  own icon and gets its original back when removed.
- **59 runes, ready to use.** 21 uncommon, 23 rare and 15 very rare runes from the three rune tables, each shipped
  as a fully coded dnd5e item in the *Wanderer Runes & Cores* compendium: activations, limited uses, saves,
  damage, temporary hit points and passive Active Effects. Carving copies the compendium item onto the sheet, so
  every rune shows up on the character sheet like any other feature. Unstable Core II spends Overload's use;
  carved runes lower the attunement maximum by one (a setting).
- **Utility and throw runes.** Fifteen non-combat runes (Hollow, Lantern Heart, Makers' Tongue, Riverbed, Stone
  Sleep, Pumice, Mole's Road, Quiet Earth, Stone Tell, Deep Ear, Masonwork, Open Seam, Mason's Hand, Hearth,
  Chips of the Core) and four runes for the grapple-throw house rule (Follow-Through, Trebuchet, Hammerstone,
  Thoroughfare). Runes carry tags shown in the picker. Nothing denies teleportation.
- **Core of the Wanderer.** A built-in core the GM seats from the core's panel. Search the Core is a 1/long rest,
  10-minute feature that spends a Rage; Awakened Core asks for Intelligence, Wisdom or Charisma after each long
  rest and applies +1 (max 20) until the next.
- **Crafting bench.** One project at a time, worked once per day. Days per rarity are world settings (defaults:
  common 5, uncommon 10, rare 50, very rare 125, legendary 250). A progress ring and bar track the work, days turn
  by world time, long rest or GM fiat, and the GM has shortcuts to add days or finish. Whatever already sits in the
  target node keeps working until the project finishes, and only then is it replaced. The picker and the bench
  carry a note that master rune-crafters may aid the work, especially on very rare runes.
- **Disenchanting and essences.** Break a magic item into an essence that keeps the original item data, then slot
  it into a node as the item itself (armor attuned but not worn).
- **Non-stacking riders.** +N weapons and armor carry their bonus to the Wanderer's weapon attacks and damage, or
  to AC. The highest bonus per kind among the nodes applies, through one actor effect each, capped by rarity.
- **GM tools.** A rune library editor (custom runes, overrides and disabling, including each rune's activation
  and uses), a layout editor for the image crop and slot positions, and a scene-control tool for the overlay.

## Safeguards

- Seating or removing a core, granting days and finishing a project are GM-only in the UI and in the API; a
  player's long rest still turns the day.
- Players can only carve from the module's own compendium. Essences cannot be duplicated, runes cannot be dragged
  in from the compendium, and the active GM's client removes anything that slips through.
- Direct installs remember attunement, equipped state and icon and restore them exactly on removal.
- Open dialogs are never re-rendered by world-time ticks or setting changes.

## First-run checklist

1. Enable the module, open the sheet as GM, press **Core**, confirm the designation.
2. Seat Core of the Wanderer; the sheet should show the feat with Search the Core linked to Rage.
3. As the player, carve Titan's Grip, press **Work**, and confirm the button locks and the chat line appears.
4. GM **Finish now**; confirm the sphere icon, the attunement maximum dropping by one, and the feature on the sheet.
5. Disenchant a +1 weapon, slot the essence, and confirm the rider effect on the actor's Effects tab.
6. Long rest as the player; confirm the day resets and the Awakened Core prompt appears.
7. Carve Overload, then Unstable Core II; use Unstable Core II and confirm Overload's use is spent.
8. Open the rune library and the layout editor as GM.

## Known limitations

- Foundry v11 only (Application v1 API and LevelDB packs). Foundry v12 is not supported by this release.
- The Awakened Core prompt appears on the client that performed the long rest.
- This release was verified headlessly (a smoke test over stubbed Foundry globals and data-model checks against
  dnd5e 3.0.4) but has not yet been played through in a live Foundry world. Anything odd belongs on the
  [issue tracker](https://github.com/Sam-W-Jones/Wanderer/issues).
