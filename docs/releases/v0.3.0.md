# The Wanderer's Core v0.3.0

Disenchanting an item into a node now takes 30 minutes instead of days of work.

**Requirements:** Foundry VTT 11 or 12, dnd5e 3.0 or later (verified against 4.4.4).

**Install or update:** in Foundry open *Add-on Modules → Install Module* and paste

```
https://github.com/Sam-W-Jones/Wanderer/releases/latest/download/module.json
```

Worlds already running an earlier version update from the Add-on Modules tab.

## What changed

- **30 minutes, not days.** Setting an essence into a node used to be a project taking the crafting days of the
  item's rarity (10 for uncommon, 50 for rare, 125 for very rare). It is now done at once, and the bench, the
  essence list, the confirmation and the chat line all state the time: 30 minutes by default, set by the new
  *Disenchanting time (minutes)* world setting. It does not use the once-per-day work allowance.
- **The bench is left alone.** Slotting an essence used to go through the single project slot, so it asked to
  abandon, and then discarded, whatever rune was being carved. Disenchanting now never touches a carving in
  progress.
- **Settings.** *Essences slot instantly* is gone. *Essences take crafting days* (off by default) restores the
  slower pace for tables that want it: an essence is queued as a project with the crafting days of its rarity,
  exactly like a rune. Carving runes is unchanged.
- Replacing an occupied node with an essence now says plainly that the occupant is replaced at once (a rune is
  lost, an essence returns to the inventory).

## Upgrading

- An essence project that was already on the bench keeps its original day count and can be finished as before.
  Setting that same essence directly from the essence list sets it at once and clears the queued project.
- The module does not advance world time; the 30 minutes are for the table to track.
